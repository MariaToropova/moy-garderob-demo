# Мой гардероб — демонстрационная версия

Статическая интерактивная витрина учебного проекта для публикации на GitHub Pages.

## Публикация

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки, включая `assets` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Укажите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Через несколько минут GitHub покажет публичную ссылку.

Эта версия не содержит базы SQLite, личного профиля или резервных копий. Все взаимодействия демонстрационные.
